# Finatix unified front-end review

## Audit findings
- Navigation split courses, levels and case studies into competing destinations and linked to a generic approach section. Start added a selector before exam discovery.
- Homepage relied on a very tall four-line hero and multiple repetitive narrative sections. Case exams were treated differently from subject papers.
- Catalogue used teal/violet/rose covers, badges and level selectors, unlike Finatix orange. Cover art overwhelmed course titles. URL filters and student progress were valuable and must stay.
- About repeated mission/vision/values with unsupported adaptation claims. Contact included fabricated example video and competency figures. Pricing used glows, hidden reveal states, decorative badges and inconsistent surfaces.
- Course shells used coloured gradients, a decorative wave and a fallback forty-hour estimate; paper pages promoted a BA1 sample even for unrelated exams.
- Auth was cramped inside a small card. Dashboard mixed bright level colours and uppercase headings. Shared controls used uppercase microtype and excessive rounding; some learning rows nested a button inside a link.
- Shared layout hid helpful/legal footer links on phones. Route transitions initially hid all content; global smooth-wheel interception was unnecessary.

## Direction and scope
An editorial product identity: Space Grotesk headings, Source Sans 3 reading text, existing orange identity, off-white/charcoal surfaces, crisp rules, restrained corners. All sixteen exams appear in their actual levels, with one Exams navigation and direct canonical links. No teaching-philosophy section, separate exam-type journeys, fabricated results or interactive homepage demo.

Existing authentication, content, filters, sales guards, payments, admin tools, enrolment and progress remain authoritative. No backend/schema/data migration or publication.
