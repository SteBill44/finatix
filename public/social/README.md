# Finatix social media assets

Brand-consistent images for social profiles. All PNG, correct pixel sizes per
platform, charcoal + orange brand with the hexagon logo and gradient wordmark.

## Profile pictures (shown as a circle — logo is centred + circle-safe)
| File | Size | Use for |
|------|------|---------|
| `fb-profile.png` | 500×500 | Facebook page profile picture |
| `instagram-profile.png` | 320×320 | Instagram profile picture |
| `linkedin-logo.png` | 400×400 | LinkedIn company page logo |

## Banners / covers
| File | Size | Use for |
|------|------|---------|
| `fb-cover.png` | 1640×624 | Facebook page cover (content centred for mobile crop) |
| `linkedin-company-cover.png` | 1128×191 | LinkedIn company page cover |
| `linkedin-personal-banner.png` | 1584×396 | LinkedIn personal profile background (bottom-left kept clear for your avatar) |

## Posts / stories
| File | Size | Use for |
|------|------|---------|
| `instagram-post.png` | 1080×1080 | Instagram feed post (square) |
| `instagram-story.png` | 1080×1920 | Instagram / Facebook story |

Notes:
- Upload as-is; all three platforms accept PNG.
- Facebook/LinkedIn crop covers differently on desktop vs mobile — key content
  is centred (or kept away from avatar overlap) so nothing important is lost.
- Regenerate/tweak text via the generator used to build these (ask Claude Code).
